# Winner Detection

## Performance Multiple

```text
Performance Multiple = Post Metric / Account Baseline Metric
```

Classification:

| Multiple | Label |
|---:|---|
| < 2× | Normal |
| >= 2× and < 3× | Watch |
| >= 3× and < 5× | Winner |
| >= 5× | Breakout |

## Winner dimensions

A post can be valuable even when it is not a raw-performance Winner.

- **Hook Winner**: unusually strong stop/initial view behavior.
- **Retention Winner**: unusually strong watch/retention.
- **Resonance Winner**: shares, saves, comments or self-projection signal.
- **Funnel Winner**: keyword comments, DMs or other lead actions.
- **Brand Winner**: especially strong fit with W.RINES worldview or positioning.

## Required annotations

For every highlighted post record:
- source account/category
- content format
- metric used
- baseline used
- performance multiple
- promoted/organic/unknown
- Hook pattern
- audience insight
- CTA/funnel
- W.RINES translation angle
- copy risk

## Do not do

- Do not compare a 20k-follower account's raw views directly with W.RINES.
- Do not call a promoted post an organic Winner.
- Do not treat connector zeros as real zeros when data quality is known to be poor.
- Do not copy the exact competitor script; extract the mechanism.
