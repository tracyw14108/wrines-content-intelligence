# Content Pattern Rules

## What counts as a reusable Pattern

A Pattern is a transferable mechanism, not a copied line.

Example:

```text
Competitor wording -> do not store as a reusable script
Abstract pattern -> "很多人以為 A，其實 B"
W.RINES translation -> use W.RINES-specific insight and examples
```

## Pattern fields

- Pattern ID
- Hook type
- Human tension / pain
- Reframe
- Proof or explanation style
- CTA type
- Funnel stage
- Relevant W.RINES pillar(s)
- Best format
- Copy risk
- Evidence notes

## W.RINES brand filter

A Pattern is useful only if W.RINES can answer it through at least one of:

- 第一印象
- 氣質
- 個人風格
- 自我表達
- Power / Warmth / Freedom
- 飾品如何參與「被看見／被感受到」

## Preferred transformations

1. Broad human problem -> W.RINES point of view.
2. Style rule -> identity / perception question.
3. Product pain -> comfort + self-expression.
4. Quiz -> personal interpretation -> jewelry recommendation.
5. Keyword CTA -> low-friction lead magnet or Charm Test.

## Avoid

- Medical diagnosis or treatment claims.
- Copying a competitor's exact sequence or wording.
- Generic trend-chasing with no bridge to the brand worldview.
- Using a viral post as proof that every similar topic will work for W.RINES.
