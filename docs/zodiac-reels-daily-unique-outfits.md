# 12 星座每日穿搭 Reels｜每日差異化標準 v1.0

## 已確認的視覺定案
- 僅製作 **Reels**，不是 IG 輪播
- 服飾單品平鋪、色票、飾品特寫；**整套穿搭展示頁使用等比例高清模特兒**
- 約 3 秒一幕，12 星座每天有自己的占星與搭配原因
- 出版用繁體中文，畫面文案不加中文句號
- 一般頁可用「更多 ＞」，結尾使用細線空心愛心「♡」
- 帳號 `@w.rines_`，內容來源列「服飾、飾品及色彩搭配：w.rines_」
- 不將服裝或飾品寫成經科學證實能改善運勢

## 唯一性約束
1. 新的上衣和下身**都需要更換**，只換顏色或同件不同色不算新造型
2. 同一星座近 30 天不重用同一個上衣或下身衣款 ID
3. 同一星座近 14 天不能重用相同的上衣品類＋剪裁或下身品類＋剪裁
4. 同一日 12 星座不重用同一上衣或下身 ID；同一完整搭配組合不可重複
5. 外套、包包、鞋款、首飾形狀、色彩和材質也應跟當日主題變化
6. 造型要能穿出門；色彩靈感以當日可核對星象為引子，但挑衣服要具備合理美學理由
7. 產出 Reels 前，先將候選寫進 `data/zodiac-reels/outfits.json`，執行 `python scripts/check_zodiac_reels_outfits.py`，不通過就重新選品
8. 商品實際上架／可售與圖片使用權限需要獨立查證；不能因舊母池照片存在就當作授權或現貨
